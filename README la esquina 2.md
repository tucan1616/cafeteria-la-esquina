# La Esquina

Landing de una cafetería de barrio especializada en empanadas y bocadillos.

- Se pueden hacer pedidos para encargar y recoger en el sitio.
- Los pedidos se hacen por WhatsApp y se pagan al recogerlos.
- Se asigna un código QR para retirar el pedido al solicitarlo en el local.
- Se emiten facturas a empresas o particulares que lo soliciten una vez pagado.
